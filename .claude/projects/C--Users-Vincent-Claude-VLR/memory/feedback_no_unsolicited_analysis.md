When the user asks to display or show data, present only the data. Do not add unsolicited observations, takeaways, or "things that stand out."

**Why:** User explicitly corrected this — they asked for a display, not analysis.
**How to apply:** Only provide interpretation or commentary when the user specifically asks for it (e.g., "what do you notice", "what stands out", "analyze this").
